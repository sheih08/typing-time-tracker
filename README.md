# Active Typing Time Tracker

Расширение для Visual Studio Code, предназначенное для автоматического отслеживания времени активной работы с кодом, ведения статистики и напоминаний о перерывах.

---

## Возможности

* **Фоновое отслеживание активности**  
  Таймер учитывает только то время, когда вы вводите или редактируете текст. При отсутствии активности более 2 минут (120 секунд) отсчет автоматически ставится на паузу.

* **Индикатор в статусной строке**  
  В нижнем правом углу отображается текущий статус:
  * `Coding: HH:MM:SS` — идет активный налог/редактирование кода.
  * `Paused (HH:MM:SS)` — таймер приостановлен из-за отсутствия активности.

* **Статистика и графика за неделю**  
  Клик по статусной строке открывает интерактивную панель с графиком активности за последние 7 дней.

* **Напоминания о перерывах**  
  При непрерывной работе в течение 1 часа расширение выводит уведомление с предложением сделать короткий перерыв.

---

## Использование

1. **Автозапуск:** Расширение активируется автоматически при старте VS Code.
2. **Просмотр статистики:**  
   * Нажмите на статусную строку внизу справа.
   * Или вызовите команду через палитру (`Ctrl+Shift+P` / `Cmd+Shift+P`):  
     `Typing Tracker: Show Statistics & Charts`
3. **Сброс текущего таймера:**  
   Через палитру команд (`Ctrl+Shift+P` / `Cmd+Shift+P`):  
   `Typing Tracker: Reset Today's Timer`

---

## Требования

* VS Code версии 1.75.0 или выше.
