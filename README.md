# Active Typing Time Tracker

Расширение для Visual Studio Code, которое считает время работы с текстом, показывает статистику за неделю и напоминает о перерывах.

---

## Возможности

* **Учет времени работы**  
  Счетчик работает, пока вы редактируете файлы, и останавливается после 3 минут без изменений. При следующем изменении отсчет продолжается.

* **Время в статусной строке**  
  Внизу справа отображается накопленное время:
  * `Coding: MM:SS` — счетчик работает.
  * `Paused (MM:SS)` — счетчик приостановлен.

  Начиная с часа время отображается в формате `H:MM:SS`.

* **Статистика за неделю**  
  Нажатие на счетчик открывает панель со временем за сегодня и графиком за последние 7 дней.

* **Напоминания о перерывах**  
  После каждого часа накопленного времени появляется предложение сделать перерыв.

---

## Использование

1. Расширение запускается автоматически после старта VS Code.
2. Редактируйте файлы — время будет учитываться в фоне.
3. Чтобы посмотреть статистику, нажмите на счетчик внизу справа или вызовите команду через палитру (`Ctrl+Shift+P` / `Cmd+Shift+P`):  
   `Typing Tracker: Show Statistics & Charts`
4. Чтобы увидеть свежие данные на графике, откройте статистику заново.

## Как устроен проект

* **`src/extension.ts`**  
  Основной файл расширения. Здесь находятся счетчик, обработка изменений текста, сохранение данных, команды и панель статистики.

* **`src/media/chart.js`**  
  Локальная библиотека Chart.js для построения графика.

* **`package.json`**  
  Описание расширения, команды VS Code, зависимости и команды сборки.

* **`package-lock.json`**  
  Зафиксированные версии зависимостей.

* **`tsconfig.json`**  
  Настройки компиляции TypeScript. Результат сборки попадает в папку `out`.

* **`.vscode/launch.json`**  
  Настройки запуска расширения для отладки.

* **`.gitignore`**  
  Исключает зависимости, результаты сборки и пакеты расширения из Git.

## Основные функции

Все функции расширения находятся в `src/extension.ts`.

* **`activate()`**  
  Запускает расширение: загружает сохраненное время, создает счетчик в статусной строке, регистрирует команды и включает секундный таймер.

* **`registerActivity()`**  
  Запоминает последнее изменение файла и возобновляет счетчик после паузы.

* **`getTodayKey()`**  
  Создает ключ для хранения данных за текущую дату: `codingTime_YYYY-MM-DD`. Дата определяется по UTC.

* **`saveTodayData()` и `loadTodayData()`**  
  Сохраняют и загружают число накопленных секунд через хранилище VS Code `globalState`. Статистика общая для разных проектов.

* **`updateStatusBar()` и `formatTime()`**  
  Обновляют статусную строку и преобразуют секунды в удобный для чтения формат.

* **`checkBreakTime()`**  
  Показывает напоминание, когда счетчик достигает очередного часа.

* **`showStatisticsPanel()`**  
  Создает панель статистики и подключает к ней локальный `chart.js`.

* **`getWebviewContent()`**  
  Подготавливает HTML панели и данные за последние 7 дней. Код внутри страницы передает эти данные в Chart.js для построения графика.

* **`deactivate()`**  
  Сохраняет накопленное время при отключении расширения.

## Как работает счетчик

1. При запуске расширение загружает сохраненное время за сегодня.
2. Каждое изменение файлового документа обновляет время последней активности.
3. Раз в секунду таймер проверяет, сколько времени прошло после изменения. Если прошло не больше 3 минут, счетчик увеличивается на секунду.
4. После 3 минут бездействия счетчик останавливается. Следующее изменение файла возобновляет учет.
5. Время сохраняется при достижении значений, кратных 30 секундам, при открытии статистики, сбросе счетчика и отключении расширения.

Изменением считается не только ручной ввод, но и вставка текста, форматирование или правки других расширений. Время между изменениями тоже учитывается, пока не наступит пауза.
